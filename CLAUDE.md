## Как работаем вдвоём (Claude Code + чат Claude)
GitHub — общий источник правды. Чат Claude читает и правит те же репозитории `portfolio` и `diary`.
- Перед любой работой: `git pull` в нужной папке (там могут быть правки из чата).
- После каждого законченного изменения: коммит с понятным сообщением по-русски и `git push`.
  Пример: «Портфолио: розы в футере — точные зоны наведения на мобильном».
- В `CHANGES.md` в корне репозитория дописывай строку: дата, что сделано, что осталось или под вопросом.
- Если решение спорное (дизайн, тексты, структура), не угадывай: оставь в CHANGES.md пометку «ВОПРОС:» — Тигран обсудит её в чате.

### Кто что делает
- Claude Code (ты): всё, что запускается на ноутбуке — git, gh, локальный просмотр, массовые правки, публикация и откат.
- Чат Claude: дизайн и решения, проверка в браузере на разных ширинах, разбор референсов, работа с телефона. Он тоже пушит в этот репозиторий.
- Решения принимаются в чате, исполнение — здесь.

### Чтобы не мешать друг другу
- Не правь один файл параллельно с чатом: перед работой `git pull`, а если Тигран сказал, что чат сейчас занят этим файлом, подожди.
- Не переписывай index.html целиком ради мелкой правки: меняй точечно, чтобы не затирать правки из чата.
- При конфликте не перезаписывай чужое (`--force` запрещён): покажи Тиграну diff и спроси.

### Как формулировать и сдавать задачу
- Задача с результатом: «сделай X, проверь на ширинах 390 и 1440, запушь».
- Перед пушем проверь: нет горизонтального скролла, нет ошибок в консоли, картинки грузятся.
- В конце коротко: что изменено, как проверено, что осталось, есть ли «ВОПРОС:».
